카카오 실시간 경로 확인 → 주소 복사 → 티맵 최종 주행

🚩 출발지

앱을 열면 자동으로 현재 위치로 출발합니다. 실패 시 집(계동) 기본값. 주소를 직접 검색해 출발지로 설정할 수도 있습니다.

📍 배송지 입력 (최대 6곳 · ★ = 최종 목적지)

즐겨찾기 칩의 🚩를 누르면 그 곳이 출발지로 설정됩니다.
거래처명 입력 시 노션 주소가 자동 채워지고, 입력 즉시 좌표가 자동 확인됩니다.
📋 버튼으로 주소를 복사 → 티맵 앱에 붙여넣어 경유지를 추가하세요.
▲▼ 순서변경 · ★ 목적지 지정 · ✕ 삭제

🚀 실행

· 목적지만 입력한 뒤 📱 티맵 앱으로 열기를 누르면 최적화 없이 바로 티맵이 열립니다.
· 🟡 카카오 네비로 열기는 출발지·경유지·목적지를 카카오내비 앱으로 함께 전달합니다 (경유지 최대 3곳 · 모바일 전용).
· 카카오 실시간 교통 정보로 총 시간/거리를 먼저 확인합니다.
· 티맵 딥링크는 공식적으로 경유지를 지원하지 않아 목적지 1곳만 전달됩니다.
· 각 배송지의 📋 복사 버튼으로 주소를 복사 → 티맵에서 붙여넣어 경유지를 순서대로 추가하세요.
